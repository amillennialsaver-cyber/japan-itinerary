# 🗾 Japan 3-Week Itinerary App

An AI-powered Next.js app that generates a beautiful, personalised 21-day Japan itinerary for couples.

## Features
- 🤖 Claude AI generates a full day-by-day itinerary
- 🎌 Covers Tokyo, Hakone, Kyoto, Nara, Osaka, Hiroshima & more
- 🌸 Customise by season, budget, and travel vibe
- 📅 Clean sidebar navigation with day-by-day detail view
- 💡 Local insider tips for each day

## Getting Started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

```bash
npm install -g vercel
vercel
```

## Environment
No `.env` setup needed when running via Claude.ai.
For local dev, set `ANTHROPIC_API_KEY` in `.env.local`.
